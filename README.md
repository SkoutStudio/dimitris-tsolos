# Strength Center · Coach Δημήτρης Τσόλος

Ιστοσελίδα του γυμναστηρίου Strength Center.

- `index.html`: αυτόνομη σελίδα (Three.js από CDN). Hero «ατσάλινο πορτραίτο» με πείρους που αλλάζουν με το scroll, 3D μπάρα στο φόντο, scroll animations.
- `img/`: φωτογραφίες από το Instagram [@tsolosdimitrios](https://www.instagram.com/tsolosdimitrios/).

Για τοπική προβολή: `python3 -m http.server` και άνοιγμα στο `http://localhost:8000`.

Εκκρεμούν η διεύθυνση και το τηλέφωνο στην ενότητα «Επικοινωνία».
